## 1. 已完成的想法(带结果)

### F · 一次性问 LLM(无进化)
- **做法**:直接让基座 LLM 一次设计 HFSP 算法,和进化后的 g1 对比。
- **结果**:one-shot 7.85% vs g1 6.96%(快速测试)→ **进化有实打实增益 ~0.9pp**。
- **意义**:回答审稿人"为什么要进化,直接问一次不行吗"——不行,进化值得。

### E · 组合拳(portfolio)
- **做法**:多个算法每个算例取最优。
- **结果**(免费从 P5d 数据算):单 g1 5.96% → 全部组合 5.74%(↓0.22pp)。
- **意义**:组合有效但增益小,**根源是算法结构单一(都近 IG)** → 引出"多样性/自适应"必要性。

### B · 少样本示范(不微调)
- **做法**:往变异提示词塞 3 个"好变异"例子(in-context learning)。
- **结果**:4.18% vs 零样本 4.11%,持平略差。
- **意义**:**提示层面学习不够** → 强化 M8(权重级微调)的必要性——论文消融里"廉价路径被证伪"的一格。

## 2. 待评估的想法

### C · rationale 语料(微调数据升级)⭐ 推荐先做
- **是什么**:每次变异,LLM 输出"我为什么把 X 改成 Y"的设计理由,攒成微调语料。
- **回答什么**:微调数据从"配置对"升级为"配置对 + 设计理由",让 LLM 学到的不只是"改了什么"还有"为什么"。
- **成本**:低(改提示词 + 攒数据,顺手)。
- **上限**:中(直接提升 M8 质量)。
- **衔接**:M8 微调的数据管线;也是论文"分析章节"的素材来源。

### A · 预言家(reward surrogate)
- **是什么**:微调一个 LLM 预测 RPD,代替昂贵真实评估 → 进化快一个量级。
- **回答什么**:评估能否被"预测"替代(痛点:评估慢,如 P5d 5h)。
- **成本**:高(双模型 + 重训循环 + 防"骗预言家"/reward hacking)。
- **上限**:中高(速度 + "LLM 既是设计师又是预言家"的双角色叙事)。
- **判断**:第二篇/扩展,不碰主线。

### D · 按类型定制(通往生成器的正门)⭐ 生成器方向的入口
- **是什么**:聚类算例(按硬度/结构特征),LLM 给**每类**生成算法——介于"一个算法"和"per-instance"之间。
- **回答什么**:自适应到底有没有用、能不能落地。
- **成本**:中高(聚类 + 按类生成 + 评估)。
- **上限**:高(如果 per-instance 生成器是终点,D 是最自然的过渡)。
- **判断**:如果决定做线程 B(生成器),从 D 进。

### H · 跨问题迁移(大故事)
- **是什么**:HFSP 学到的设计能力,搬到流水车间 / JSP 上测。
- **回答什么**:LLM 学到的是"通用设计技能"还是"只对 HFSP 有效"。
- **成本**:高(要另一个基准 + 全部重跑)。
- **上限**:很高("学到通用算法设计"能冲大期刊)。
- **判断**:M8 成功后作为续篇;也是论文 future work 的实锤。

### G · meta-meta(LLM 设计自己的进化)
- **是什么**:不只搜算法,还让 LLM 搜进化策略本身(变异率/选择压力/反思频率)。
- **回答什么**:进化本身能否被自动设计。
- **成本**:很高。
- **上限**:高(自适应的进化,新颖)。
- **判断**:最狂、最不急着做;做成是第二篇的大新闻。

## 3. 优先级与路线图

```
加分层(顺手做):    C ──► 直接升级 M8 数据,性价比最高
野心层(可选):      D ──► 通往生成器方向(线程 B)的正门
远期层(大故事):    H ──► 跨问题迁移,上限最高
二篇素材:          A / G
```

**推荐顺序**:
```
主线(保毕业):    M8 微调(被 F/E/B 证明是唯一学习杠杆)
加分层(顺手):    C(rationale 语料)→ 并入 M8
野心层(可选):    D(按类型定制)→ 若想冲生成器
远期(第二篇):    H(跨问题) / A(预言家) / G(meta-meta)
```
