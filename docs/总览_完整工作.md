## 2. 核心概念(一句话)

- **元层进化**:搜的不是解,是算法(AlgorithmSpec)
- **组件组合**:算法 = 结构 × 组件 × 参数,LLM 只改配置不写代码
- **塌缩**:选出一个最好算法后 10 代不再提升(我们的实验亲历)
- **防塌缩**(创新②):多样性惩罚 + 洞察 Archive
- **自进化**(创新①):进化数据 DPO→RLVR 偏好对齐(延期)

## 6. 关键发现(论文素材)

1. **LLM 进化算法 ≥ IG**(三 run 一致: 5.96/6.00/5.98 < 6.12)
2. **LLM 搜索 ≈ 随机搜索**(测试集打平)→ 不靠"LLM 搜索更强"
3. **LLM 重新发明 IG**:从 SA-like 出发,自己加上"破坏-重建+局部搜索"
4. **策略塌缩复现**:init 赢 10 代 best 平线 → 大改的诊断依据
5. **设计空间顶区平坦**:好配置成片(4.5-5%), 随机也能抽到
6. **评估成本是大瓶颈**:大算例 + 局部搜索超预算 → 需要并行/多seed
